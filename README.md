# CrewSphere — launch film

A 60-second product film for **CrewSphere**, a fleet crew-operations platform
for cruise lines: crew pools, assignments, rotations, relief chains, readiness,
travel, in-port manning, documents and analytics.

Every screen in the film is a live product screen captured from the running
application — not a mockup.
